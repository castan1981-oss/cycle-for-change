# Instagram — working folder (not published)

Netlify only serves `cfc-site/`, so nothing here goes live.

Run the specialist with `@instagram-specialist` in Claude Code, or just ask
for Instagram work and it will be picked up.

- `data/` — drop Instagram Insights exports here (Meta Business Suite →
  Insights → Export, or Accounts Center → Download your information).
  Per-post CSV, audience/follower CSV, Reels and Stories CSVs, and any
  comment exports. The agent reads whatever is here.
- `campaigns/` — one markdown file per campaign, `YYYY-MM-<slug>.md`, with
  goal, hypothesis, calendar, drafts, and the outbound-comment log.
- `reports/` — monthly reports `YYYY-MM.md` and reply batches
  `replies-YYYY-MM-DD.md` ready to paste.

Robert posts, replies, and follows. The agent only drafts.
